# ⚡ Crypto Analytics & Module Dashboard

A modern, responsive cryptocurrency analytics and module monitoring dashboard built with **React 19**, **Vite**, and modular CSS.

---

## 🚀 Features

- **Live Analytics Overview**: Real-time market metrics, price tracking, and trading module status.
- **Modular Component Architecture**: Extensible `ModuleCard` and `Dashboard` components.
- **Fast Development Experience**: Powered by Vite and Oxlint for ultra-fast HMR and linting.
- **Responsive Modern UI**: Sleek dark-mode aesthetic optimized for multi-device displays.

---

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Linter**: Oxlint
- **Styling**: Vanilla CSS with tailored design tokens

---

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/omniversodigital/crypto-dashboard.git
cd crypto-dashboard

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
